# TacticTrail Dataset Register

This document tracks the cybersecurity knowledge sources used by TacticTrail. The original source files remain outside version control; only small, documented samples and reproducible processing scripts are committed.

## Dataset inventory

| File | Source URL | Records / page-equivalents | Licence / terms | Downloaded on |
|---|---|---|---|---|
| `data/raw/enterprise-attack-20.0.json` | [MITRE Enterprise ATT&CK v20.0 STIX 2.1 JSON](https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/enterprise-attack/enterprise-attack-20.0.json) | 26,690 STIX objects in the bundle (not 26,690 pages) | [MITRE ATT&CK Terms of Use](https://attack.mitre.org/resources/legal-and-branding/terms-of-use/) | 2026-10-23 |
| `data/raw/enterprise_techniques.json` | Generated from the Enterprise dataset by `scripts/extract_techniques.py` | 706 active attack-technique records, including sub-techniques | Same MITRE terms as the source | 2026-10-24 |
| `data/sample/techniques_sample.json` | Generated by `scripts/extract_techniques.py` | 10 representative test records (first 10 after sorting by ID) | Same MITRE terms as the source | 2026-10-24 |

**Important:** The date for the two generated files is the documentation date; update it to the actual execution date if different.

## Processing methodology

1. Download the pinned Enterprise ATT&CK v20.0 STIX 2.1 collection.
2. Read the collection's `objects` array.
3. Keep objects whose STIX `type` is `attack-pattern`.
4. Exclude objects marked `revoked` or `x_mitre_deprecated`.
5. Retrieve the MITRE technique ID and official URL from `external_references`.
6. Extract the name, description, tactic names from `kill_chain_phases`, sub-technique flag, and STIX ID.
7. Export the 706 filtered records locally, and publish a small 10-record sample for reproducibility.

Command (run from the repository root):

```powershell
python scripts/extract_techniques.py
```

Observed output for the initial Enterprise dataset:

```text
Total STIX objects: 26690
Active techniques extracted: 706
Sample records saved: 10
Example: T1001 Data Obfuscation
```

These are processing counts, **not an evaluation result**. No AI search accuracy has been measured yet.

## Coverage and remaining work

- **Included now:** Enterprise ATT&CK active techniques and sub-techniques.
- **Not yet extracted:** Enterprise groups, software, mitigations, and relationships; Mobile ATT&CK; ICS ATT&CK.
- **College requirement:** At least 1,500 technique, group, and software records across domains, with 2,000+ page-equivalents. We have not yet verified this total.
- **Page-equivalent measurement:** To be defined and documented consistently. STIX object count must not be reported as page count because it includes metadata and relationships.
- **Next ingestion tasks:** Add groups and software, then add other ATT&CK domains, while deduplicating by STIX ID and keeping the source version and official URLs.

## File storage and reproducibility

- Keep `data/raw/` in `.gitignore` because it contains large original and derived files.
- Commit the extraction script and `data/sample/techniques_sample.json` as a reproducible, small example.
- Preserve the original source/version so results can be regenerated.
- Do not store banking incident notes or tenant information in public sample data.
